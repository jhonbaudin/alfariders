# Alfa Riders Peru

Sitio publico estatico para Alfa Riders Peru, comunidad multimarca de motoaventura enfocada en motos doble proposito, rutas, clinicas y experiencias de aventura.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run deploy
```

## Alcance actual

- Frontend publico estatico con Vite, React y TypeScript.
- Identidad visual basada en los logos y flyers de referencia.
- Deploy compatible con GitHub Pages mediante `gh-pages -d dist`.

## Limitacion importante

GitHub Pages solo sirve archivos estaticos. CMS, panel administrativo real, membresias, pagos, webhooks, PostgreSQL y almacenamiento privado requieren hosting server-side o una arquitectura separada.
