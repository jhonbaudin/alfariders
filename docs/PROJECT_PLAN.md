# Project Plan

## Objetivo

Crear el centro digital oficial de Alfa Riders Peru para comunicar identidad, publicar rutas, mostrar experiencias, presentar clinicas, manejar galerias, exhibir merchandising y preparar el crecimiento hacia membresias y ecommerce.

## Alcance actual

La implementacion inicial es un sitio publico estatico deployable en GitHub Pages. Incluye landing institucional, paginas separadas de rutas, comunidad, clinicas, contacto y merchandising, assets de marca y documentacion de evolucion.

## Fase 1 - MVP publico

- Inicio con identidad de marca.
- Paginas separadas para comunidad, clinicas y contacto.
- Seccion de galeria institucional en el landing.
- Pagina `/rutas` para la ruta mensual y el historico.
- Pagina `/merchandising` para catalogo de merchandising Alfa.
- Uso del logo oficial.
- Uso visual de flyers como referencia grafica.
- SEO base y Open Graph inicial.
- Deploy estatico a GitHub Pages.

## Fase 2 - Plataforma dinamica

- Migrar a Next.js con App Router y hosting server-side.
- Incorporar Payload CMS, PostgreSQL y almacenamiento S3/R2.
- Crear panel administrativo real.
- Implementar autenticacion de miembros.
- Proteger briefing, GPX, punto privado y recursos internos.

## Fase 3 - Membresia y pagos

- Implementar `PaymentProvider`.
- Primera integracion recomendada: Culqi.
- Suscripcion mensual/anual.
- Webhooks idempotentes.
- Auditoria de eventos de pago.
- Cancelacion clara de membresia.

## Fase 4 - Ecommerce

- Carrito.
- Ordenes.
- Variantes, tallas y stock.
- Cupones.
- Pagos.
- Envios.
- Historial de compras.
- Cambios y devoluciones.

## Contenido pendiente

- Mision, vision e historia oficial.
- Precios y beneficios comerciales.
- Numero de WhatsApp.
- Correo operativo.
- Patrocinadores confirmados.
- Textos legales revisados.
- Politica de privacidad final.
