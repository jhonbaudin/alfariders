# Design System

## Direccion visual

Alfa Riders debe sentirse profesional, elegante y aventurero. El lenguaje visual debe hablarle a motociclistas de doble proposito de alta gama: tecnica, ruta, montana, preparacion y comunidad.

## Paleta

- Negro: base premium y contraste.
- Amarillo: acento principal operativo.
- Blanco: lectura, version de logo sobre fotografia.
- Gris piedra: textura, montaña y neutralidad.
- Azul oscuro ambiental: profundidad nocturna.
- Rojo tierra: acento muy secundario para calidez.

## Logo

- Version amarilla: principal sobre fondos oscuros.
- Version blanca: sobre fotografia o fondos de alto contraste.
- Version horizontal: navegacion y espacios compactos.
- Pendiente: SVG oficial, favicon, isotipo, versiones responsive y archivos optimizados.

## Tipografia

- Titulares: condensada, pesada y uppercase.
- Texto: sans serif limpia y legible.
- Uso actual: `Barlow Condensed` para titulares e `Inter` para cuerpo, con fallbacks CSS.

## Fotografia

- Motos, montaña, trocha, altura, briefing y comunidad.
- Evitar stock generico.
- Evitar exceso de filtros que oculten la moto o el terreno.

## Texturas

El grunge debe usarse como acento, no como base completa. La interfaz debe mantener limpieza, jerarquia y legibilidad.

## Accesibilidad visual

- Contraste alto.
- Botones con area tactil minima de 44px.
- Textos escalables sin depender solo del color.
- Mobile-first.
